# Agent 独立升级

TyloInfer推理核心、完整官方DSH运行包、外部产品插件是三个独立更新单元。当前启动器只选择已安装运行包、核对兼容性并启动，不下载、安装、重写Core或自动迁移用户数据。独立Studio继续使用自己的构建与设置，不因DSH升级而要求构建Agent Client。

## 更新前的只读预检

从项目根目录执行；以下路径为使用者选择的安装和私有状态位置：

```sh
python scripts/agent_host.py --runtime-root <candidate-runtime> --plugins-root <product-plugins> --state-root <private-state> --check
```

预检包括CLI／base／Web版本一致、两个插件的明确兼容声明及产物存在，并检查既有profile中两个产品包的绑定是否属于所选插件安装。它不启动Host、推理进程或浏览器，不写profile，也不重建、删除或替换链接。

当前插件只声明0.2.2-rc.2。未测的新版本应被拒绝，不应为了通过预检把兼容声明改成任意版本或仅修改候选manifest版本。缺少客户端产物也须明确失败，不从另一安装补读。

`--prepare-only`与正常启动也先检查全部既有插件绑定；即使第二个插件才发生冲突，也不应先创建第一个链接、profile清单或默认配置。断开的旧绑定同样拒绝，不覆盖为新安装。

## 状态与回退

- 替换运行包前先停止对应Host；不得把活动服务的普通目录复制冒充一致的恢复快照。当前工具没有自动停止、快照或恢复入口。
- 私有状态独立于安装目录。需要备份时应保留完整的原生会话、设置、凭据、媒体和工作区状态；仅保留浏览器连接文件不能恢复会话或授权。
- 运行包和插件兼容性拒绝发生在用户状态写入前。可重新选择原兼容运行包和原插件安装；不需要为拒绝重建profile或清空用户设置。
- `--plugins-root`选择了新安装而既有profile仍绑定旧安装时，当前产品明确拒绝自动改绑。保留旧安装和原状态，或在独立私有副本中演练；不要删掉旧链接来强行通过。跨插件安装的原子改绑／回退仍未实现。
- 真正的新发行版运行过后，是否能读回旧版本、是否需要恢复备份，必须由该发行版的数据兼容证据决定。升级前应在隔离状态副本中检查会话、设置和凭据能否恢复。
